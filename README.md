# AI Agent Workshop

Materials for a workshop on building AI agents for Credit Management and Collections teams (October 2026).

## Contents

| Folder | What's inside |
| --- | --- |
| `Presentation-10-2026/` | Slide deck: *AI Agent Instructions Guide* (PDF) |
| `AI-Agent-Build1/` | **Build 1 · Overnight Inbox Triage**: an agent that reviews the last 24 hours of email, categorises and labels it, and produces a morning handover report |
| `AI-Agent-Build2/` | **Build 2 · Credit Application Review**: an agent that checks a customer's application and financials against credit policy and drafts a recommendation. Includes mock sample documents (credit policy, credit application, financials) |
| `AI-Agent-Build3/` | **Build 3 · Private Company Research**: an agent that researches non-listed customers or prospects using public web sources, registers and filings |

Each build folder contains a **Prompts (paste-ready)** `.docx` with agent instructions you can copy straight into your AI tool.

## Using the builds

1. Open the build's Prompts document and paste the instructions into your agent's configuration.
2. Connect the inputs the agent needs: a mailbox for Build 1, the sample PDFs for Build 2, web search for Build 3.
3. Run the agent and review its output.

> The Build 2 sample documents are mock data for demonstration only.
